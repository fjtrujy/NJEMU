Validated on 2026-09-21 against the translation system after T8.

## PS2 matrix

The same 16 GUI/core/flag combinations were cross-compiled successfully with the current PS2 toolchain:

- CPS1: 4/4
- CPS2: 4/4
- MVS: 4/4
- NCDZ: 4/4

All 16 PS2 builds generated the exact same five-pack hash set as Desktop, including the same aggregate digest above.

This proves that core selection, `SAVE_STATE`, `COMMAND_LIST`, platform selection, and cache-enabled cores do not alter message IDs, catalog contents or the pack schema.

## Stable IDs

`tests/ui_text_id_tests.c` continues to lock representative IDs from across the namespace, including normalized stretch/button/autofire/reset-help/ROM-info groups and `UI_TEXT_MAX`. It is executed in every Desktop matrix configuration. The PS2 builds consume the same unconditional `messages.def`/`ui_text_ids.h`; there are no feature/platform conditionals in the ID namespace.

## Generator/loader robustness

`tests/translation_pack_tests.py` now contains 20 tests and explicitly covers:

- complete catalog success;
- missing key rejection;
- extra key rejection;
- duplicate key rejection;
- bad escape rejection;
- `printf` contract mismatch rejection;
- V1 string-blob overflow rejection;
- deterministic English pack SHA-256;
- all-language round trips;
- schema hash stability;
- bad magic/version/language/count/reserved/size/schema;
- out-of-range offsets;
- truncation;
- missing NUL termination.

The C loader tests additionally cover real pack loading, English fallback and missing-English failure.

## PSP / ADHOC

The build system and translation source are now platform/feature independent, and the PSP Makefile/CMake packaging paths generate the same packs. Native PSP compilation is not available in this local environment, so `ADHOC=ON` on PSP is not claimed as executed. This remains the only external build/runtime validation item from T9.

## T9 result

The same prebuilt language pack is valid across all four cores and every locally buildable tested feature combination on Desktop and PS2. The translation namespace is no longer coupled to `EMU_SYSTEM`, `SAVE_STATE`, `COMMAND_LIST`, `USE_CACHE` or platform-specific storage code.
