Classic arcade emulation across modern and legacy hardware

NJEMU

A shared, open-source emulator for Capcom CPS1/CPS2 and SNK Neo Geo MVS/AES/CD, targeting PSP, PlayStation 2, PlayStation Vita, and Desktop from one codebase.

Download NJEMU Open ROM Converter

Supported systems

Four arcade families, one frontend

CPS1

Capcom Play System 1.

CPS2

Capcom Play System 2, with optional streaming-cache support on constrained hosts.

Neo Geo MVS/AES

SNK cartridge hardware with shared metadata and processed/cache tooling.

Neo Geo CD

Neo Geo CD/NCDZ emulation with MP3-backed CD audio support.

Supported platforms

Built for constrained consoles and Desktop

PSP PlayStation 2 PlayStation Vita Desktop

Official downloads use one recommended full feature configuration per platform. Advanced build combinations remain available to developers through CMake and CI.

Release archives never contain ROMs or BIOS files. Each archive includes CPS1, CPS2, MVS, and NCDZ builds for the selected host. Desktop downloads are split by operating system because native executables are not cross-platform.
