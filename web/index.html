NJEMU

A shared, open-source emulator for Capcom CPS1/CPS2 and SNK Neo Geo MVS/AES/CD, targeting PSP, PlayStation 2, PlayStation Vita, and Desktop from one codebase.

Supported systems

Four arcade families, one frontend

CPS1

Capcom Play System 1.

CPS2

Capcom Play System 2, with optional streaming-cache support on constrained hosts.

Neo Geo MVS/AES

SNK cartridge hardware with shared metadata and processed/cache tooling.

Neo Geo CD

Neo Geo CD/NCDZ emulation with MP3-backed CD audio support.

Optional game reference

Command lists

View game instructions, special moves and button combinations from the emulator menu. Command lists are optional: games work normally without a command.dat file.

01

Download command data

Obtain a MAME Plus! command.dat archive and extract the file named command.dat. It is supplied separately from NJEMU.

MAME Plus! 0.168 command data (external ZIP)

02

Copy to the emulator folder

Place command.dat next to the selected core's executable or in its runtime data directory, not inside roms/. One file covers multiple games; you do not need one per ROM.

PSPPSP/GAME/MVSPSP/command.dat PS2command.dat PS Vitaux0:data/mvs/command.dat Desktopcommand.dat
03

Open Command List in a game

Launch a supported game, press Start + Select to open the emulator menu, and select Command List. If no matching entry exists, NJEMU shows a message instead of blocking gameplay.

Compatibility: MAME Plus! command.dat format, including the UTF-8 MAME Plus! 0.168 file in NJEMU builds with issue #24 support. Older tagged releases may not display its Japanese text correctly.
